# EliGSiR publication provenance matrix

This export has no inherited Git history. The matrix below is therefore the
release record for retained code: it classifies each retained code path by
explicit rule, and the contract test checks that every retained code file has
one winning rule. A higher-priority exception is intentional when a broad
project rule would otherwise hide an upstream or vendored path.

The GraphDeco classification is grounded in the retained Inria/GRAPHDECO
headers, the unchanged `LICENSE.md`, and corresponding baseline paths in an
archived reference checkout (import commit `324e95f5`; its local path is
intentionally omitted from this public export). It does not grant a new
license or replace the Inria/MPII terms, and it is not legal clearance.
The project-original classification means authored or substantially modified
EliGSiR project code according to the reference checkout. Those files are
available under Apache-2.0 as recorded in [`docs/RELEASE_RIGHTS.md`](RELEASE_RIGHTS.md)
and [`LICENSES/Apache-2.0.txt`](../LICENSES/Apache-2.0.txt); this remains a
file-level grant, not a blanket relicensing statement for the export.

Dependency-level provenance is tracked separately in
[`docs/THIRD_PARTY_PROVENANCE.yaml`](THIRD_PARTY_PROVENANCE.yaml), with the
corresponding notices in [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).
That manifest records the local Chart.js 4.4.7 and PlayCanvas 2.18.1 hashes
and MIT sources, while keeping incomplete components explicitly release-blocked.
The fused-ssim row records a chosen full publication reproducibility pin, not
historical build provenance. The code-file matrix below remains conservative: a
third-party path can be classified as unresolved even when a mechanical
license notice has been found, because source mapping and redistribution scope
are separate questions.

## Legal blockers

- The Apache-2.0 grant is limited to the `eligsir-original` rule and does not
  apply to GraphDeco-derived or third-party paths.
- The GraphDeco/Inria-MPII research/evaluation terms remain applicable to the
  derived rows; `LICENSE.md` is retained unchanged for that reason.
- Obtain and retain authoritative notices/licenses for LPIPS, ORB-SLAM3, and
  every runtime dependency before a public release; the dependency manifest
  records the retained web-asset notices and their exact local hashes.
- LPIPS vendored mapping and weights, ORB-SLAM3/wrapper source scope, RVizSplat,
  and external dataset terms remain explicit release blockers in the dependency
  manifest. The neutral ROCm gsplat fork identity/source/rights evidence is
  retained and its dependency row is no longer release-blocked.
- Dataset licenses and separately distributed ROS2/RGB-D repositories are out
  of scope for this source export and must be reviewed by their own owners.
